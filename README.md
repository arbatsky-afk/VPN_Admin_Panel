# VPN Admin Panel

Локальная Windows-панель для развёртывания и администрирования собственного
VPN-сервера. Приложение подключается к VPS по SSH, не требует браузера и не
поднимает доступный извне локальный веб-сервер.

В репозиторий также входит отдельный Monitor для периодической проверки
подключений через изолированный процесс Mihomo и отправки уведомлений в
Telegram.

## Возможности

- поэтапный Deploy серверных Components: Base + Security, Xray, Hysteria2,
  Mieru, Docker, Nginx и Netdata;
- просмотр состояния и управление установленными службами;
- создание, продление и удаление VPN-пользователей;
- сборка и публикация объединённых подписок;
- Backup и Restore управляемой конфигурации;
- проверка SSH, восстановление доступа после переустановки VPS и безопасная
  перезагрузка сервера;
- удалённые операции через авторизованный Telegram-бот;
- независимый Monitor подключений с системным треем и Telegram-уведомлениями;
- операторские инструменты для AmneziaWG и сборки дерева прокси Mihomo.

## Требования

- Windows;
- Python `>=3.13,<3.14`;
- доступные команды OpenSSH `ssh` и `ssh-keygen`;
- VPS с Ubuntu 24.04 для модульного Deploy.

Для администрирования нужен SSH-доступ к собственному серверу. После
переустановки VPS доступ можно восстановить по паролю `root`, но только после
проверки host-key fingerprint через доверенную консоль провайдера.

## Быстрый запуск

Клонируйте репозиторий и подготовьте виртуальное окружение из его корня:

```powershell
git clone https://github.com/arbatsky-afk/VPN_Admin_Panel.git
cd VPN_Admin_Panel
py -3.13 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Затем запустите нужное приложение:

- `run-admin-panel.vbs` — основная панель;
- `run-monitor.vbs` — Monitor;
- `run-desktop-suite.vbs` — оба приложения вместе.

При первом запуске откройте **Settings**, добавьте SSH-ключи и проверьте порт.
Панель всегда начинает работу в режиме **Read only**; операции, изменяющие
сервер, требуют явного включения **Edit mode**.

Подробности: [запуск desktop-панели](docs/Инструкции/01%20—%20Запуск%20desktop-панели.md),
[SSH-доступ](docs/Инструкции/02%20—%20SSH-доступ.md) и
[модульный Deploy](docs/Инструкции/03%20—%20Модульный%20деплой.md).

## Безопасность

- Проверяйте Server IP, Alias и текст подтверждения перед каждой изменяющей
  операцией.
- Не принимайте новый SSH host key без сравнения fingerprint с независимым
  доверенным источником.
- Создавайте актуальный Backup перед повторным Deploy или изменением серверной
  конфигурации.
- Не публикуйте каталог `runtime/`: в нём находятся локальные настройки и
  рабочее состояние приложений.

Python-зависимости закреплены с SHA-256 в `requirements.lock`. Сведения о
сторонних компонентах находятся в
[Third-party notices](supply_chain/THIRD_PARTY_NOTICES.md), а полный inventory —
в [CycloneDX SBOM](supply_chain/sbom.cdx.json).
