# Установка AmneziaWG и подготовка клиентских конфигураций

AmneziaWG устанавливается и управляется приложением Amnezia VPN, а не VPN Admin
Panel. Панель может подготовить Docker и административный SSH-доступ.

> **Ограничение:** ручная установка AmneziaWG пока не входит в полностью
> поддерживаемый сценарий проекта. Panel не управляет её пользователями,
> конфигурацией или UDP-портом.

## Перед началом

На сервере должны быть установлены и активны:

1. **Base + Security**;
2. **Docker**.

Также подготовьте публичный IPv4 и актуальную версию приложения Amnezia VPN.
Для входа приложения на сервер можно использовать пароль или поддерживаемый им
закрытый SSH-ключ. После настройки **Base + Security** не включайте парольный
SSH-вход ради Amnezia: используйте ключ. Рекомендуется создать для приложения
отдельную пару, чтобы не передавать ему основной административный ключ.

## Отдельный SSH-ключ для Amnezia (рекомендуется)

RSA 4096 в формате PEM остаётся совместимым консервативным вариантом. Чтобы
создать такую пару, в PowerShell выполните:

```powershell
ssh-keygen -t rsa -b 4096 -m PEM -f $env:USERPROFILE\.ssh\id_rsa_amnezia
```

Рекомендуется задать passphrase. Команда создаст закрытый ключ и файл
`id_rsa_amnezia.pub`. Если выбран вход по ключу, закрытый ключ понадобится
приложению Amnezia, а публичный нужно добавить на сервер.

## Добавление публичного ключа

Через действующий административный SSH-доступ или консоль провайдера добавьте
содержимое `id_rsa_amnezia.pub` отдельной строкой в
`/root/.ssh/authorized_keys`. Затем проверьте вход:

```powershell
ssh -i $env:USERPROFILE\.ssh\id_rsa_amnezia root@SERVER_IP
```

Если используете отдельный ключ, не продолжайте установку, пока вход им не
подтверждён.

## Установка в Amnezia VPN

1. Добавьте новый сервер в приложении Amnezia VPN.
2. Укажите публичный IP и пользователя `root`.
3. Передайте приложению закрытый SSH-ключ и его passphrase. Пароль используйте
   только если парольный SSH-вход уже разрешён политикой сервера; не включайте
   его специально для установки AmneziaWG.
4. Выберите **Automatic installation**.
5. Дождитесь завершения установки AmneziaWG.
6. Создайте тестового клиента и проверьте подключение к интернету.

Приложение Amnezia создаёт контейнер и публикует выбранный UDP-порт. Для сетей,
которые могут блокировать высокие UDP-порты, рекомендуется выбрать свободный
порт не выше `9999`, например `585` или `1234`. Убедитесь, что порт не занят
другой службой.

Вручную добавлять правило в общий `nftables` Panel не следует. После установки
проверьте во вкладке **Management** состояние Docker и опубликованный порт
AmneziaWG. Если подключение не работает, учитывайте, что отдельного
управляемого Component для этого порта пока нет.

## Преобразование клиентского конфига в YAML

1. Положите файлы `*.conf` и `*.vpn` в каталог `tools\in\`
2. Запустите `tools\awg2yaml.cmd` двойным кликом.
3. Готовые `*.yaml` появятся в том же каталоге рядом с исходниками.

За один запуск обрабатываются все подходящие файлы. Ошибка в одном файле не
останавливает остальные: причина выводится отдельной строкой, а в конце
показывается сводка вида `Converted: 2, failed: 1`. Окно ждёт нажатия клавиши,
поэтому результат можно прочитать.

Полученные YAML-файлы можно объединить с другими прокси и подготовить для
mihomo по инструкции
[«Сборка дерева прокси для mihomo»](<11 — Сборка дерева прокси для mihomo.md>).

## Безопасность

- Не передавайте закрытый SSH-ключ в переписке или журнале.
- Не заменяйте основной административный ключ отдельным ключом Amnezia.
- Не отключайте рабочий административный доступ до проверки нового ключа.
- Не редактируйте вручную общий управляемый firewall Panel.
