# Управление пользователями

Вкладка **Users** показывает и изменяет пользователей установленных Xray,
Hysteria2 и Mieru, а также сохраняет их connection-файлы локально.

## Перед началом

- Выберите сервер в поле **Server IP**.
- Убедитесь, что **Check SSH** завершается успешно.
- Установите через модульный Deploy хотя бы один поддерживаемый VPN Component.

Просмотр таблицы и **Save user links** доступны в режиме **Read only**. Действия
**Add user**, **Add protocols** и **Delete user** изменяют сервер и требуют
**Edit mode**.

Справа от таблицы находятся три компактные кнопки-иконки по вертикали: сверху
**+** — Add user, затем **Add protocols**, ниже — Save user links. Название
каждого действия показывается в tooltip при наведении и доступно средствам
accessibility.

## Работа с таблицей

1. Откройте **Users** и дождитесь окончания загрузки.
   При открытии Panel проверяет регистрацию и Users-возможности VPN Components,
   не запуская полный набор серверных health-проверок, затем загружает таблицу.
2. Найдите пользователя и проверьте, в каких протоколах он существует.
3. Выберите требуемое действие:

   - **Add user** — создаёт нового пользователя сразу во всех доступных VPN
     Components и обновляет таблицу; чтобы сохранить его connection-файлы,
     после обновления выберите созданную строку и нажмите **Save links**;
   - **Add protocols** — для пользователя активной строки без дополнительного
     подтверждения создаёт учётные записи во всех доступных протоколах, где его
     ещё нет; существующие UUID, пароли и записи не изменяются. Кнопка доступна,
     только если строка выбрана и хотя бы один доступный протокол отсутствует;
   - **Save links** — заново получает и сохраняет connection-файлы выбранного
     пользователя;
   - корзина **Delete user** в колонке **Actions** — после подтверждения удаляет
     пользователя именно этой строки из всех протоколов, где он существует;
     выбирать строку перед удалением не требуется.

После **Add user**, **Add protocols** или **Delete user** дождитесь обновления
таблицы. Не используйте предыдущие данные таблицы как подтверждение результата,
пока обновление не завершилось.

## Имя пользователя

- Разрешены латинские буквы, цифры и дефис: `A-Z`, `a-z`, `0-9`, `-`.
- Имя нельзя редактировать непосредственно в таблице.
- **Add user** отклоняет имя, которое уже существует хотя бы в одном доступном
  протоколе. Для дополнения существующего пользователя используйте
  **Add protocols**.

## Connection-файлы

Panel сохраняет доступные URI и YAML-файлы в настроенный локальный каталог.
Полные пути созданных файлов показываются в **Operation log**. Повторное
сохранение обновляет файлы того же пользователя.

Не публикуйте и не пересылайте connection-файлы без необходимости: они
содержат данные доступа к VPN.

Чтобы объединить несколько сохранённых ссылок в один URL, используйте
[Subscriptions](<07 — Subscriptions.md>).

## Ошибки

- Если таблица не загрузилась, проверьте Server IP и **Check SSH**, затем
  откройте вкладку заново.
- Если операция завершилась с предупреждением или неизвестным результатом,
  дождитесь повторного чтения таблицы перед следующим изменением.
- При смене сервера или вкладки дождитесь завершения или отмены текущей
  операции.
